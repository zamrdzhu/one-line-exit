One line: the funniest single-line resignation letter. Written for make.fun's "The One-Line Exit" bounty.

## The line

> I resign, effective immediately: the printer has jammed for the last time, and frankly, so have I.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because it reads like a letter a person could actually send — "I resign, effective immediately" — and then the reason is gloriously petty: the printer. The twist is that the human and the machine share the same failure: both jammed, both done. The last four words turn a complaint about office equipment into a confession of burnout, which is the whole resignation in miniature.
